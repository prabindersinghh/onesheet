# Privacy

onesheet collects no data. It has no server, no account, no analytics and no telemetry.

Everything runs on your own computer. The repository you choose, the fact ledger, the renders and the PDF stay on your machine, in your project folder and in `.onesheet` in your home folder.

To build a page, it downloads public files from outside services: the repository you name, if it's a public GitHub URL, fonts from Google Fonts, the three.js library from unpkg, and its build tools from PyPI and npm. It may also read public counts, such as GitHub stars, from public APIs. Those requests carry only what's needed to fetch the files, never your code or your page.

Claude itself reads the repository while it works, under your own Claude account and its terms.

Questions: [open an issue](https://github.com/prabindersinghh/onesheet/issues).
